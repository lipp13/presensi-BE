BAGIAN 2: AUTENTIKASI (AUTH FLOW)
================================================================================

2.1 Login Siswa
- Method  : POST
- URL     : http://localhost:5000/api/auth/login
- Headers : Content-Type: application/json
- Body (JSON):
  {
    "email": "siswa@tarunabhakti.sch.id",
    "password": "Password123!"
  }
- Expected Response (200 OK):
  * Salin nilai "access_token" dari respon ini untuk digunakan di pengujian berikutnya!
  {
    "success": true,
    "message": "Login berhasil.",
    "data": {
      "access_token": "eyJhbGciOi...",
      "user": {
        "id": "uuid-siswa",
        "full_name": "Alif Alfathar",
        "role": "user"
      }
    }
  }

2.2 Login Admin
- Method  : POST
- URL     : http://localhost:5000/api/auth/login
- Headers : Content-Type: application/json
- Body (JSON):
  {
    "email": "admin@tarunabhakti.sch.id",
    "password": "Admin123!"
  }
- Expected Response (200 OK):
  * Salin nilai "access_token" milik admin ini untuk pengujian modul Admin!

2.3 Profil Pengguna (Me)
- Method  : GET
- URL     : http://localhost:5000/api/auth/me
- Headers : 
  * Authorization: Bearer <access_token_siswa>
- Expected Response (200 OK):
  Menampilkan data lengkap profil user yang sedang login.

2.4 Ubah Password (Sedang Login)
- Method  : POST
- URL     : http://localhost:5000/api/auth/change-password
- Headers : 
  * Authorization: Bearer <access_token_siswa>
  * Content-Type: application/json
- Body (JSON):
  {
    "old_password": "Password123!",
    "new_password": "PasswordBaru123!"
  }
- Expected Response (200 OK):
  { "success": true, "message": "Password berhasil diperbarui." }

2.5 Lupa Password (Kirim Link ke Email)
- Method  : POST
- URL     : http://localhost:5000/api/auth/forgot-password
- Headers : Content-Type: application/json
- Body (JSON):
  {
    "email": "siswa@tarunabhakti.sch.id"
  }
- Expected Response (200 OK):
  { "success": true, "message": "Tautan instruksi reset password telah dikirimkan ke email Anda jika terdaftar." }

BAGIAN 3: ALUR PRESENSI SISWA (ATTENDANCE FLOW)
*Gunakan Header: Authorization: Bearer <access_token_siswa>*
================================================================================

3.1 Cek Status Presensi Hari Ini (Sebelum Absen)
- Method  : GET
- URL     : http://localhost:5000/api/attendance/today
- Headers : Authorization: Bearer <access_token_siswa>
- Expected Response (200 OK):
  {
    "success": true,
    "data": {
      "has_checked_in": false,
      "has_checked_out": false,
      "attendance": null
    }
  }

3.2 Presensi Masuk (Check-in) - SUKSES (Dalam Radius 100m)
- Method  : POST
- URL     : http://localhost:5000/api/attendance/check-in
- Headers : 
  * Authorization: Bearer <access_token_siswa>
  * Content-Type: application/json
- Body (JSON):
  {
    "latitude": -6.899380,
    "longitude": 107.618610,
    "accuracy": 12,
    "photo": "data:image/jpeg;base64,/9j/4AAQSkZJRgABAQEASABIAAD/2wBD..."
  }
- Expected Response (201 Created):
  {
    "success": true,
    "message": "Presensi masuk (check-in) berhasil dicatat.",
    "data": {
      "status": "CHECKED_IN",
      "check_in_distance": 0,
      "check_in_photo_path": "https://..."
    }
  }

3.3 Uji Tolak Anti-Duplikasi Check-in
- Jalankan kembali request 3.2 di atas pada hari yang sama.
- Expected Response (400 Bad Request):
  {
    "success": false,
    "message": "Anda sudah melakukan presensi check-in untuk hari ini.",
    "error": { "code": "ALREADY_CHECKED_IN" }
  }

3.4 Uji Tolak Anti-Cheat: Anomali Fake GPS (Accuracy <= 0)
- Body: { "latitude": -6.899380, "longitude": 107.618610, "accuracy": 0 }
- Expected Response (400 Bad Request):
  {
    "success": false,
    "message": "Nilai akurasi GPS tidak valid atau terindikasi penggunaan mock location/Fake GPS.",
    "error": { "code": "SUSPECTED_FAKE_GPS" }
  }

3.5 Uji Tolak Anti-Cheat: Sinyal GPS Lemah (Accuracy > 50m)
- Body: { "latitude": -6.899380, "longitude": 107.618610, "accuracy": 85 }
- Expected Response (400 Bad Request):
  {
    "success": false,
    "message": "Akurasi sinyal GPS perangkat Anda terlalu rendah (±85 meter)...",
    "error": { "code": "GPS_ACCURACY_TOO_LOW" }
  }

3.6 Uji Tolak Luar Radius Kantor (Koordinat Monas Jakarta)
- Body: { "latitude": -6.175392, "longitude": 106.827153, "accuracy": 15 }
- Expected Response (400 Bad Request):
  {
    "success": false,
    "message": "Presensi ditolak. Lokasi Anda berada di luar radius kantor presensi...",
    "error": { "code": "LOCATION_OUT_OF_RANGE" }
  }

3.7 Presensi Pulang (Check-out) - SUKSES
- Method  : POST
- URL     : http://localhost:5000/api/attendance/check-out
- Headers : 
  * Authorization: Bearer <access_token_siswa>
  * Content-Type: application/json
- Body (JSON):
  {
    "latitude": -6.899380,
    "longitude": 107.618610,
    "accuracy": 15,
    "photo": "data:image/jpeg;base64,/9j/4AAQSkZJRgABAQEASABIAAD/2wBD..."
  }
- Expected Response (200 OK):
  {
    "success": true,
    "message": "Presensi pulang (check-out) berhasil dicatat.",
    "data": {
      "status": "COMPLETED",
      "check_out_time": "2026-09-04T...",
      "check_out_distance": 0
    }
  }

3.8 Uji Tolak Dobel Check-out
- Jalankan kembali request 3.7 di atas pada hari yang sama.
- Expected Response (400 Bad Request):
  {
    "success": false,
    "message": "Anda sudah melakukan presensi pulang (check-out) hari ini.",
    "error": { "code": "ALREADY_CHECKED_OUT" }
  }

3.9 Cek Status Presensi Hari Ini (Setelah Selesai)
- Method  : GET
- URL     : http://localhost:5000/api/attendance/today
- Headers : Authorization: Bearer <access_token_siswa>
- Expected Response (200 OK):
  {
    "success": true,
    "data": {
      "has_checked_in": true,
      "has_checked_out": true,
      "attendance": { "status": "COMPLETED" }
    }
  }

3.10 Melihat Riwayat Presensi Siswa
- Method  : GET
- URL     : http://localhost:5000/api/attendance/history?limit=10
- Headers : Authorization: Bearer <access_token_siswa>
- Expected Response (200 OK):
  Menampilkan daftar riwayat absensi siswa yang login terurut dari yang terbaru.

BAGIAN 4: MODUL KHUSUS ADMIN (MONITORING & EXPORT EXCEL)
*Gunakan Header: Authorization: Bearer <access_token_admin>*
================================================================================

4.1 Monitoring Presensi Hari Ini Seluruh Siswa
- Method  : GET
- URL     : http://localhost:5000/api/admin/attendance/today
- Headers : Authorization: Bearer <access_token_admin>
- Expected Response (200 OK):
  Menampilkan total siswa yang hadir hari ini beserta detail foto dan waktu masuk/pulang.

4.2 Seluruh Riwayat Presensi Semua Siswa
- Method  : GET
- URL     : http://localhost:5000/api/admin/attendance/history?page=1&limit=20
- Headers : Authorization: Bearer <access_token_admin>
- Expected Response (200 OK):
  Menampilkan data seluruh siswa dengan pagination.

4.3 Melihat Daftar Siswa PKL Terdaftar
- Method  : GET
- URL     : http://localhost:5000/api/admin/students
- Headers : Authorization: Bearer <access_token_admin>
- Expected Response (200 OK):
  Menampilkan list siswa PKL (Nama, NISN, Sekolah, Jurusan).

4.4 Admin Mendaftarkan Siswa Baru
- Method  : POST
- URL     : http://localhost:5000/api/admin/students
- Headers : 
  * Authorization: Bearer <access_token_admin>
  * Content-Type: application/json
- Body (JSON):
  {
    "email": "siswa_baru@tarunabhakti.sch.id",
    "password": "PasswordBaru123!",
    "full_name": "Muhammad Dennis",
    "nisn": "5432167890",
    "school": "SMK Taruna Bhakti",
    "major": "Teknik Komputer dan Jaringan"
  }
- Expected Response (201 Created):
  { "success": true, "message": "Akun siswa PKL berhasil didaftarkan." }

4.5 Export Rekap Presensi ke File Excel (.xlsx)
- Method  : GET
- URL     : http://localhost:5000/api/admin/attendance/export
- Headers : Authorization: Bearer <access_token_admin>
- Expected Response:
  Di Thunder Client akan langsung terdownload/terbuka file binary spreadsheet Excel (.xlsx).
  Format file resmi ber-header instansi Balai SDA dengan tabel lengkap.

BAGIAN 5: PENGUJIAN KEAMANAN ROLE (RBAC SECURITY)
================================================================================

5.1 Siswa Coba Mengakses Menu Admin (Uji Forbidden)
- Method  : GET
- URL     : http://localhost:5000/api/admin/attendance/today
- Headers : Authorization: Bearer <access_token_siswa>  <-- Menggunakan token siswa
- Expected Response (403 Forbidden):
  {
    "success": false,
    "message": "Akses ditolak. Fitur ini hanya dapat diakses oleh role: admin. Role Anda: user",
    "error": { "code": "FORBIDDEN" }
  }

5.2 Request Tanpa Token Otentikasi (Uji Unauthorized)
- Method  : GET
- URL     : http://localhost:5000/api/attendance/today
- Headers : (Tanpa Header Authorization)
- Expected Response (401 Unauthorized):
  {
    "success": false,
    "message": "Akses ditolak. Token otentikasi tidak disertakan...",
    "error": { "code": "UNAUTHORIZED" }
  }
